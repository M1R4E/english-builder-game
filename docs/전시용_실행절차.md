# 전시용 실행 절차 (학술제 당일)

게임 주소: **https://m1r4e.github.io/english-builder-game/**

## 학술제 전날까지 (인터넷이 되는 곳에서)

1. **전시에 쓸 기기와 브라우저로** 위 주소를 엽니다. (기기마다 따로 해야 합니다. 크롬·엣지·사파리 권장)
2. 메인 화면 오른쪽 위 **톱니바퀴(설정)** → 아래쪽 **진행자용** → **"오프라인 사용: 준비됨"**인지 확인합니다.
   - "준비 중"이면 인터넷이 연결된 채로 잠시 기다렸다가 설정 창을 다시 엽니다.
3. 와이파이(인터넷)를 끄고 **새로고침**한 뒤, 레벨을 한두 개 끝까지 플레이해 봅니다.
4. 휴대폰·태블릿이라면 브라우저 메뉴의 **"홈 화면에 추가"**를 하면 앱처럼 전체 화면으로 열 수 있습니다.
5. 연습으로 쌓인 기록이 있으면 설정 → 진행자용 → **새 체험자 시작**을 눌러 둡니다.

## 학술제 당일

- 체험자가 바뀔 때마다: 설정 → 진행자용 → **새 체험자 시작** → **새로 시작**
  - 체험자는 익명 번호(P001, P002 …)로만 구분됩니다. 이름 같은 개인 정보는 저장하지 않습니다.
  - 이전 체험자의 기록은 지워지지 않고 남습니다.
- 처음 하는 체험자에게는 **설정 → 난이도 "쉬움"**을 권하면 단어 뜻과 안내가 보입니다.
- 화면이 좁아 3D 건물이 잘 안 보이면, 카드 판 위쪽 **손잡이를 아래로 끌어내리면** 건물이 크게 보입니다.

## 끝난 뒤: 기록 모으기

- 설정 → 진행자용 → **기록 내보내기 (CSV)** → 엑셀에서 열 수 있는 파일이 내려받아집니다.
- 기록은 **기기마다 따로** 저장됩니다. 여러 기기를 썼다면 기기마다 내보내야 합니다.
- 기록 항목: 레벨, 예상 점수, 첫 점수, 최고 점수, 예상−첫 점수, 공사 대금, 별, 완공, 제출 횟수, 힌트 단계, 층수 실수, 오류 종류, 정답 예시를 봤는지, 자기 설명 답, 걸린 시간, 난이도 설정
- 연구 자료로 쓸 때는 기록 목적과 활용 방법을 안내하고 동의를 받는 절차를 따로 준비합니다(기획서 7).

## 주의할 점

- 브라우저의 **"인터넷 사용 기록 삭제"(사이트 데이터 삭제)**를 하면 저장된 게임 파일과 **학습 기록이 모두 지워집니다.** 기록을 먼저 내보내세요.
- **시크릿(사생활 보호) 창**에서는 기록이 남지 않습니다. 일반 창을 쓰세요.
- 게임을 고쳐서 새로 배포했다면, 전시 기기에서 인터넷이 될 때 한 번 다시 열어 새 버전을 받아 두세요 (자동으로 바뀝니다).
- 사전·사후 설문은 지금 **꺼져 있습니다**. 쓰려면 문항을 정해 `src/data/survey.js`에 넣고 켠 뒤 다시 배포합니다.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| 화면이 하얗게만 나온다 | 새로고침. 계속되면 인터넷이 될 때 한 번 다시 열기 |
| "3D 화면을 불러오지 못했어요" | 오래된 기기·브라우저일 수 있음. 다른 기기 사용 (문장 만들기와 채점은 그대로 됨) |
| 오프라인에서 안 열린다 | 그 기기에서 인터넷이 될 때 한 번도 안 열었거나, 사이트 데이터가 지워진 경우. 인터넷 연결 후 다시 열기 |
| 레벨이 2개만 보인다 | 정상. 하나를 완공하면 다음 난이도 주문서가 도착 (새 체험자는 처음부터) |

## 학생 개인 기기로 체험하고 구글 폼으로 결과 받기 (2026-10-16 추가)

- 학생은 자기 휴대폰의 **크롬·사파리**로 게임 주소를 엽니다. (카카오톡 안에서 바로 열지 않기, 시크릿 창 쓰지 않기)
- 10개 레벨을 모두 완공하고 우편함으로 돌아오면 **최종 결과 보고서**가 자동으로 뜹니다.
  - 시간이 모자라면 우편함 위쪽 **결과 보고서** 버튼으로 그때까지의 **중간 결과 보고서**를 볼 수 있습니다.
- 학생은 이 화면을 **캡처**해서 사후 검사 구글 폼에 첨부합니다.
  - 구글 폼의 "파일 업로드" 문항은 응답자가 **구글 계정에 로그인**해야 쓸 수 있습니다.
- 보고서 내용: 레벨별 예상 점수, 첫 점수, 최고 점수, 제출 횟수, 힌트 단계, 완공(별). 예상·첫 점수·제출·힌트는 그 레벨을 **처음 도전한 판** 기준입니다. 점수는 100점 만점(게임 속 금액 ÷ 1,000)입니다.
