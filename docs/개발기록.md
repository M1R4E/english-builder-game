# 개발 기록

## 확정된 기획 결정 (2026-10-15)

| 번호 | 내용 | 결정 |
|---|---|---|
| ① | 지붕 표시 | **방 하나가 완성되면 정답 여부와 관계없이 그 방의 지붕이 나타난다.** 방의 세부 요소가 정답과 맞는지, 그 방이 필요한 방인지와는 무관하다. 정답 판정은 제출 후에 한다. **방 = 절(층) 하나**: 한 절에 필요한 자리(주어·동사·목적어 등)에 카드가 모두 놓이면 그 층의 지붕이 나타난다. 맨 위층이 아닌 층에는 처마 모양의 작은 지붕을 붙인다. (2026-10-15 확정) |
| ② | 예상 점수와 비교할 점수 | 메타인지 비교 = 첫 제출 점수. 완공·별 = 최고 점수. 둘 다 기록. |
| ③ | 보상 | 완공 70점↑. 별 ★70 / ★★85 / ★★★95. 예측 배지(차이 ≤10 "정확한 예측", ≤20 "거의 정확")는 별과 별도. 힌트 사용 감점 없음. "끝까지 수정" 배지. 모든 값 0~100. |
| ④ | 난이도 설정 | 문장은 그대로 두고 도움의 양(빈자리 표시, 문법 팁, 오답 유도 카드 수, 단어 뜻 기본값)을 바꾼다. |
| ⑤ | 레벨 잠금 | 모두 열어 두고, 최근 3개 결과로 "추천" 표시. |
| ⑥ | 정답 예시 | 2번 제출해도 완공 못 하면 "정답 예시 보기" 활성화. 기록에 "정답 참고" 표시(감점 없음). |
| ⑦ | 여러 체험자 | "새 체험자 시작" 버튼. 익명 번호로 기록 분리. 개인 정보 수집 안 함. |
| ⑧ | 불안 설문 | 4단계에서 틀만 만들고 기본은 꺼 둔다. 문항은 사용자가 제공. |
| ⑨ | 레벨 문장 | 계획서의 초안을 바탕으로 3단계에서 확정. 영어 선생님 검토 권장. |
| ⑩ | 프로젝트 위치 | `문서\english-builder-game` |
| ⑪ | 필수 성분 누락 | 4개 채점 항목과 **별도 기준**. 빠진 필수 성분 **하나마다 40점** 감점(`config.js`의 `MISSING_ROLE_PENALTY`). 빠진 성분 때문에 확인할 수 없는 항목은 **감점하지 않는다**("확인 못 함"). 성분 하나만 빠져도 최대 60점이라 완공할 수 없다. (2026-10-15 확정) |

## 0단계: 개발 환경 (2026-10-15)

- winget으로 Node.js LTS(v24.20.0, npm 11.19.0)와 Git(2.55.0)을 설치했다.
  - 참고: Microsoft Store 소스에서 인증서 오류가 나서 `--source winget`을 지정해 설치했다.
- GitHub Desktop은 아직 설치하지 않았다. GitHub에 올릴 때 설치한다.

## 1단계: 기본 구조 (2026-10-15) ✅

**한 일**
- Vite + React 19 + Three.js 0.186 프로젝트를 만들었다. 테스트 도구 Vitest도 설치했다.
- 기본 레이아웃: PC는 3D와 패널 좌우 배치, 1023px 이하는 위아래, 599px 이하는 모바일용 간격.
- `BuildingRenderer`: 장면·카메라·조명·땅, 마우스/터치 회전, 크기 변경 자동 대응, 건물 크기에 맞춘 카메라 거리, 부품 등장 애니메이션, 메모리 정리(dispose).
- 저사양 기기(CPU 4코어 이하 또는 모바일)에서는 그림자를 끄고 해상도를 낮춘다.
- 확인용 샘플 집: 기초, 주어 기둥(주황), 동사 기둥(파랑), 벽, 문, 창문, 지붕, 계단, 울타리, 나무.

**테스트 결과**
- `npm run build` 성공. Three.js 때문에 JS 파일이 커서(압축 시 약 210KB) 크기 경고가 뜨지만, 지금은 문제가 되지 않는다.
- 브라우저에서 PC, 태블릿(768×1024), 모바일(375×812) 화면을 확인했다. 3D 건물이 보이고, 가로 스크롤과 콘솔 오류가 없다.
- 수정한 문제 두 가지:
  - 화면이 느리게 그려지면 등장 애니메이션도 같이 느려져 반쯤 지어진 건물이 보였다. 실제 시계 기준으로 바꿔 해결했다.
  - 모바일에서 "설정" 버튼이 넓게 늘어나던 문제를 고쳤다.

**남은 점**
- 패널의 카드와 버튼은 아직 자리만 잡아 둔 것이고 작동하지 않는다. 2단계에서 연결한다.
- 모바일에서 건물이 약간 작게 보인다. 5단계에서 카메라 거리를 조정한다.

## 2단계: 레벨 1개로 핵심 게임 (2026-10-15) ✅

**플레이 흐름**: 레벨 선택 → 예상 점수 입력 → 카드로 문장 조립(건물이 바뀜) → 제출 → 점수·점검 결과·예측 비교 → 고쳐서 다시 제출

**새로 만든 파일**
| 파일 | 하는 일 |
|---|---|
| `src/config.js` | 배점(30/30/25/15), 완공 70점, 별 기준, 예측 배지 기준 |
| `src/data/levels/level01.js` | 레벨 1 「고양이의 낮잠 집」: The cat sleeps. |
| `src/data/levels/index.js` | 레벨 목록. 데이터에 문제가 있는 레벨은 "준비 중"으로 표시 |
| `src/game/analyzeSentence.js` | 카드 → 절(층)과 성분으로 분석, 문장 글자 만들기 |
| `src/game/scoring.js` | 규칙 기반 채점 |
| `src/game/reward.js` | 별·완공·예측 배지 계산 (문장 점수와 예측 정확도를 따로 계산) |
| `src/game/validateLevel.js` | 레벨 데이터 오류 검사 |
| `src/game/session.js` | 플레이 상태 (카드 추가·빼기·순서 바꾸기·되돌리기·제출) |
| `src/building/makeBlueprint.js` | 카드 → 건물 설계도 (어떤 부품이 채워졌는지) |
| `src/building/buildParts.js` | 설계도 → 3D 부품 (기둥, 벽, 방 칸, 가구, 지붕, 계단, 울타리, 깃발) |
| `src/building/labels.js` | 3D 화면의 글자 표지판 ("주어 ?", "⚠ 동사 확인") |
| `src/components/*` | 화면 조각 (레벨 선택, 의뢰, 예상 점수, 카드, 문장, 힌트, 결과) |
| `tests/*.test.js` | 자동 테스트 30개 |

- 1단계의 샘플 집 `demoHouse.js`는 설계도 방식으로 대체되어 삭제했다.

**건물 규칙 (구현됨)**
- 빈자리는 반투명 파란색 + "주어 ?" 같은 글자로 표시한다(시각적 힌트).
- 주어 카드는 왼쪽 기둥, 동사 카드는 오른쪽 기둥이 된다.
- 주어와 동사가 모두 있으면 벽이 생긴다.
- 그 절의 필수 자리가 모두 채워지면 정답 여부와 관계없이 지붕이 생긴다.
- 벽의 앞면은 열어 두는 "인형의 집" 방식이라 방 안이 보인다.
- 제출하면 틀린 성분 위에 "⚠ ○○ 확인", 빠진 성분 자리에 "🚧 ○○ 없음" 표지판이 뜬다. 특별 조건을 지켰으면 울타리, 70점 이상이면 깃발이 생긴다.
- 카드를 바꾸면 바뀐 부품만 다시 만들어 등장 애니메이션을 보여 준다. 지운 부품은 메모리에서 해제한다.
- 2층 이상, 계단, 목적어·보어 칸, 가구도 코드로는 만들어 두었고 자동 테스트로 확인했다. 실제 화면 확인은 3단계에서 해당 레벨을 넣을 때 한다.

**채점 방식** (결정 ⑪ 반영 후)
- **필수 성분 누락 (별도 기준):** 레벨의 `structure.clauses[절].slots`에 적힌 성분이 빠지면, 빠진 성분 하나마다 총점에서 40점을 뺀다.
- **채점 항목(checks):** 순서대로 확인한다. 각 항목은 한 범주에만 속한다.
  - **확인 못 함**(`requires`의 성분이 빠짐): 배점 그대로 준다. 누락 감점에 이미 포함되어 있어서다.
  - **확인 보류**(`dependsOn`의 앞 항목이 실패): 0점. 예: "검증된 자연스러운 표현"(10점)은 다른 항목이 모두 통과해야 확인한다.
- 정답 목록에 없지만 오류도 없는 표현은 자연스러움 5점과 함께 "확실히 판단하지 못함"이라고 솔직하게 표시한다.
- 처음에 있던 "주어 있음 / 동사 있음" 항목(각 6점)은 누락 감점과 겹치므로 없앴다. 그 배점은 어순(15점)과 수 일치(15점)로 옮겼다.

**레벨 1 대표 답안 점수** (자동 테스트로 고정)
| 답안 | 점수 | 결과 |
|---|---|---|
| The cat sleeps. | 100 | ★★★ |
| The cat the cats sleeps. | 85 | 완공 ★★ (겹친 카드 지적) |
| The cat sleep. | 75 | 완공 ★ (수 일치 지적) |
| Sleeps the cat. | 75 | 완공 ★ (어순 지적) |
| The cats sleep. | 75 | 완공 ★ (의미: 한 마리 지적) |
| The cat slept. | 65 | 공사 중 (현재 시제 조건 지적) |
| Sleeps. / The cat. | 60 | 공사 중 (필수 성분 누락 −40) |
| The cats. | 35 | 공사 중 (동사 누락 −40, 의미 −15, 자연스러움 보류 −10) |

**테스트 결과**
- 자동 테스트 34개 통과(결정 ⑪ 반영 후). 레벨 1 카드 5장으로 만들 수 있는 325가지 배열을 모두 채점했다.
  - 점수는 모두 0~100 사이 정수이고, 같은 답은 항상 같은 점수가 나온다.
  - 100점은 검증된 정답 하나뿐이다.
  - 필수 성분이 빠진 배열은 모두 70점 미만이다.
- 레벨 데이터 검사기도 강화했다.
  - 카드를 확인하는 항목에 `requires`가 빠져 있으면 오류로 알린다.
  - 필수 성분(slots)이 잘못 적혀 있으면 오류로 알린다.
- 빌드 성공.
- 브라우저(PC·모바일)에서 처음부터 끝까지 플레이했다.
  - 레벨 선택 → 예상 → 카드 추가 → 기둥 생김 → 지붕 생김 → 제출(81점, 동사에 ⚠) → 고치기 → 재제출(100점, ★★★, 울타리·깃발)
  - 힌트, 되돌리기, 순서 바꾸기, 빼기가 작동한다.
  - 모바일에서 가로 스크롤과 콘솔 오류가 없다.
- 고친 문제
  - PC에서 패널이 길어지면 3D 화면도 같이 길어지던 문제: 3D 화면을 화면 높이에 고정했다.
  - 버튼 글자가 줄바꿈되던 문제를 고쳤다.
  - 나무가 주어 기둥을 가리던 문제: 나무를 건물 뒤로 옮겼다.

**아직 안 된 것**
- 진행 상황(별, 완공)은 새로고침하면 사라진다. → 4단계에서 브라우저 저장소에 저장한다.
- 난이도 선택, 단어 뜻 보기, 정답 예시 보기, 기록 저장 → 4단계
- 모바일에서 3D 글자 표지판과 건물이 작다. → 5단계
